## 4. DESIGN TOKENS (condensed from Design System — full spec in that file)

**Fonts:**
- Display / Hero / Hooks / Poster titles: **Electro Shakel** — short 2–8 words only. NEVER body, tables, legal.
- Everything else: **Poppins** — Body, UI, buttons, docs, slides, social support text. Hierarchy: H2 Bold/SemiBold, H3 SemiBold, Body Regular 16px, Caption Medium 12px, Mono for code snippets only.

**Colors:**
```
--sr-navy-950: #020617
--sr-navy: #0A1931        (primary dark / premium)
--sr-blue-deep: #102A56
--sr-blue: #2563EB         (brand / CTA)
--sr-blue-bright: #3B82F6
--sr-blue-light: #60A5FA
--sr-blue-pale: #DBEAFE
--sr-blue-surface: #EFF6FF
--sr-white: #FFFFFF
--sr-surface: #F8FAFC
--sr-border: #E2E8F0
--sr-text-secondary: #475569
--sr-text-muted: #64748B
--sr-text-primary: #0F172A
```
Ratio: 50–65% white/neutral, 20–30% navy, 5–15% brand blue. Strong light-mode identity — do NOT make everything dark navy.
Gradients restrained only: Navy→Deep, Deep→Brand, Brand→Light. No rainbow/neon/purple-cyber.

**Shape:** Engineered geometry. Radius 4px technical, 8px UI, 12px cards, 16px large. No pills everywhere.
**Spacing:** 4/8 system: 4,8,12,16,24,32,40,48,64,80,96,128.
**Buttons:** Primary blue filled (Explore Programs), Secondary white with border (View Curriculum), Text (Learn More →). Short action copy, never CLICK HERE.

**Anti-style (BANNED):** AI-slop, generic robots, glowing brains, holograms, cyberpunk overload, matrix rain, neon-green hacker, purple AI gradients, glassmorphism excess, 3D chrome text, circuit-board filler, floating nodes, stock handshakes, fake terminals, decorative meaningless code, over-designed posters.

**Human + AI principle:** Human central, AI = amplifier layer. Visual flow: HUMAN → KNOWLEDGE → AI → EXECUTION → OUTCOME. Never imply AI replaces people.
**Cognition loop (use often):** LEARN → DO → RECALL → APPLY → BUILD → REFLECT ↺ / ATTENTION → UNDERSTANDING → RECALL → APPLICATION → MASTERY.

**QA before delivery (Design QA + 5-sec test):**
Brand? Logo correct? Electro Shakel selective? Poppins readable? Blues restrained? Contrast? Aligned? Whitespace intentional? Understandable in 5 sec (WHO SkillReigns / WHAT AI education / WHY practical skill / FEEL premium-human / NEXT clear CTA)? Claim defensible? Premium, futuristic, human?

## 7. HOW TO CREATE TEMPLATES/DOCS WITH AI (workflow for agents)

When Paris says e.g. "make Offer Letter" / "cool event ad" / "corporate stuff":

1. **Identify tag + item.** Map request → taxonomy §5. E.g. Offer Letter → `[SR-DOC-BK] Offer Letter`. Announce tag + folder path. If ambiguous, ask (max 1 clarifying Q).
2. **Read context.** Load `context.md` (this file) + item `README.md` + `spec.md` + relevant Design System sections. Check logo map §3, tokens §4.
3. **Corporate doc defaults (SR-DOC-BK):**
   - Format: A4, Poppins 11–12pt body, Electro Shakel for cover title only, navy header with MAIN logo left + `Empowering Humans with AI` right, footer with CIN/addr/contact + page X of Y + Doc ID `SR-DOC-XXX-v1.0` + classification.
   - Palette: white surface, navy headings, brand blue for CTA/table header, pale blue callouts.
   - Generate as clean **Markdown + print-ready HTML** (inline CSS, Poppins via system stack) in `output/`. Never output .docx binary — HTML prints to PDF.
   - Legal docs (Enrollment T&C, NDA, Influencer Agreement): placeholders `[BRACKETED]`, signature blocks, no fake legal advice — mark `DRAFT — legal review required`.
   - Certificates: white/light, deep blue, MAIN logo, subtle geometry, verification ID + QR placeholder, signature fields. Minimal, official, modern.
4. **Visual defaults (SR-VISUAL-BK):** Hook (Electro Shakel) → Idea → Evidence/Value (Poppins) → Brand → CTA. 1080×1080 IG, 1200×627 LinkedIn/banner, strong whitespace, 1 idea per visual, blue/white hierarchy. Provide copy + layout spec + image prompt; never generate busy AI-slop art.
5. **Video defaults (SR-VIDEO-BK):** Script + shot list + lower-thirds + end-card (Mono-White on navy) + caption file. Voice of Rauhaan = ElevenLabs trained voice — script in his factual, inspiring tone, no gimmicks.
6. **Merch/physical (SR-BRANDING-BK):** Front = SkillReigns (small chest / centered), Back = one of `SKILL RULES.` / `EMPOWERING HUMANS WITH AI` / `LEARN. BUILD. DEFEND. WITH AI.` (program only). Understated. Provide dieline + placement + mono version. Bags from scratch = tech-minimal navy + blue interior.
7. **Course (SR-COURSE-BK):** Hierarchy MODULE → CONCEPT → EXPLANATION → EXAMPLE → TRY IT → RECALL. Readability > decoration. Recall prompts + exercises mandatory.
8. **QA + deliver.** Run checklist §4 + 5-sec test. Report: files created, tag/thread title suggestion (`[SR-DOC-BK] Offer Letter — v1.0 for review`), open questions, next step. Never auto-send to Rauhaan — Paris reviews first.
9. **Thread rule (Rauhaan's order):** one collateral = one thread. When generating, suggest thread title with tag, keep discussion isolated.

Copy rules: specific, factual, constructive, human, confident. No superlatives without evidence. No employment guarantees. CTA always clear (Explore Programs / Enroll / Contact).
