## Merch rules
- Front: `SkillReigns` (small chest/centered) with MAIN logo or icon. Back (pick ONE): `SKILL RULES.` / `EMPOWERING HUMANS WITH AI` / program-only `LEARN. BUILD. DEFEND. WITH AI.`
- Single-color items (pen, journal deboss, stamp): Mono-Dark on light, Mono-White on navy.
- Signage/standees/posters: poster hierarchy SKILLREIGNS → PROGRAM/EVENT → BIG IDEA → VALUE → DETAILS → PROOF → CTA. Large type, blue system, clean diagrams. Physical signature line: `SKILL RULES.`
- ID cards: photo, name, role/batch, ID no., QR, emergency line; navy band with Mono-White logo.
- Desk mats: Outline-logo as faint texture (6–10%) + cognition loop microprint edge.
- Each item output/: dieline/dimensions .md + placement spec + color/mono variants + mockup prompt. No production without Paris + Rauhaan sign-off.
