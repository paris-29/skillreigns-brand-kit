## Corporate doc standard (AI must follow)
- A4. Poppins body 11–12pt. Electro Shakel ONLY on cover/section titles (2–8 words).
- Header: MAIN logo `skillreigns-main-with-typo.png` left; `Empowering Humans with AI` right; thin brand-blue rule below.
- Footer: SkillReigns Technologies Pvt. Ltd. + contact + page X of Y + Doc ID + `Confidential` where applicable.
- Palette: white/#F8FAFC surface, navy #0A1931 headings, #2563EB table headers/CTAs, #EFF6FF callouts.
- Output: clean Markdown + print-ready HTML (inline CSS) in item `output/`. HTML prints to PDF. Never binary .docx.
- Placeholders in [BRACKETS]. Signature blocks with Name/Title/Date/Sign. No fake CIN, numbers, or legal advice.
- Certificates: white/light, deep blue, MAIN logo, subtle geometry, verification ID + QR placeholder, 2 signatures. Minimal, official, modern — never traditional ornamental.
- Logo: main default. Mono-Dark for B/W-legal single-color. Mono-White only on navy cover bands. Outline-logo NEVER as header — background watermark at 4–8% only.
- QA: Design QA + 5-sec test (WHO/WHAT/WHY/FEEL/NEXT). Legal docs marked DRAFT until lawyer clears.
