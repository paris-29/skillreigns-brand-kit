# Canva Upload Pack — SR-DOC-BK Editable Masters (v1.0)

13 blank Word masters. Upload each `.docx` to Canva → it opens as a fully editable
design. Blue `[BRACKETED]` text = fill-in fields.

## What's here

- `01_…_SR-DOC-01.docx` … `13_…_SR-DOC-13.docx` — the 13 official documents, blank.
- `00_BRAND-ASSETS/` — logos to drop into every design (main, icon, mono ×2).
- `Canva-Folder-Tree.md` — exact folder structure to create in Canva Projects.

## Import into Canva (per file, ~2 min each)

1. Canva → **Projects → Uploads → Upload files** → pick the `.docx`. Canva converts it
   to an editable design (fonts map to Poppins automatically — Poppins is native in Canva).
2. Open it. Replace the header/footer text as needed; drop the real logo from
   `00_BRAND-ASSETS/logo-main.png` if the emblem needs resizing
   (`skillreigns-main-with-typo.png` = full lockup for covers).
3. **Lock brand elements**: select logo strip + footer → Lock (padlock icon), so editors
   can't nudge them.
4. **Save as template**: Share → **Brand template** (needs Canva Pro/Teams) → move it
   into the matching folder from `Canva-Folder-Tree.md`. Team now uses File → Make a
   copy per issue — the master stays clean.
5. Blue `[FIELDS]` stay as-is in the master; editors replace them per issue.

## Fonts

- **Poppins** (body/everything): native in Canva, zero setup.
- **Electro Shakel** (display titles only): NOT in Canva by default. Brand Kit →
  Upload fonts → add the licensed `.ttf/.otf`. Until then, titles import in a fallback
  — re-set them to Electro Shakel once uploaded (or Poppins SemiBold as stopgap).

## Bulk Create (certificates, offer letters, receipts)

1. Open the master (e.g. `09_Certificate`) → **Apps → Bulk Create** → Enter data manually
   (or CSV with columns matching the blue fields: LEARNER FULL NAME, PROGRAM, CODE…).
2. Right-click a blue field → **Connect data** → pick the column. Generate → Canva
   spits out one finished design per row. Review, download as PDF.
